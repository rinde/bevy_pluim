# `combo.rs`

`Combo`: a button that opens a `List` in a popup.

Read this before changing `src/combo.rs`. When the module's behaviour changes, update this file in the same PR.

Cross-cutting design: [popups](../design/popups.md), [lists and selection](../design/lists-and-selection.md).

## Details

`Combo`: a button (a label-only `PushButton` showing the optional `ComboPlaceholder(String)` of the combo, "Select.." by default, while nothing is selected: put with the combo or inserted later it changes a live combo; the accessible value stays empty for no selection, `a_combo_shows_its_placeholder_while_nothing_is_selected_and_the_selection_after`; with a `Chevron` `Icon` child, a 16 px triangle image the library draws and tints with `text_primary`) that opens a `List` in a `Float`, `ComboState` (open/closed), closes on an outside click or when an ancestor scrolls (`panel_scroll_closes_combo.ron`). While open, `place_open_lists` (`PostUpdate`, before layout) puts the list right under the button, left edges aligned, so it follows the button when a scroll area around it scrolls; the list is kept 10 px inside the window's left and right edges and goes above the button when it would run off the bottom, like a palette combo's popup (`combo_keeps_list_inside_window.ron`) A rename of a selected item updates the button text (`item_text_change`, which re-runs `update_selection`; the placeholder stays while nothing is selected; `renaming_the_selected_item_updates_a_combos_button_and_popup_but_not_its_placeholder`). To a screen reader the `ComboButton` is a `Role::ComboBox` without a label, its value the text of the selected items joined with ", " (empty for none; not the placeholder or the chevron), `expanded` while open and `controls` its `ComboList` (`combo_accessible_combo_box.ron`) `ComboRefs` on the combo (private fields, getters `button()` and `list()`; immutable, reflected, built only by the widget); `ComboButton` and `ComboList` are public markers The button colours (`handle_combo_button_mouse_events`), the open/close side effects (`ComboState::on_insert`: `Unreachable`, visibility, `InputFocus`, `expanded`), the outside-click rule and the accessibility node are shared with `ColorPaletteCombo` through `popup.rs`; a `Combo`'s list counts as inside an outside click only for a selection of many items, which stays here.
