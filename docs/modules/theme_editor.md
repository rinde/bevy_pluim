# `theme_editor.rs`

`ThemeEditor`: a card that edits the `Theme` in use, every color slot and number, while the widgets follow.

Read this before changing `src/theme_editor.rs`. When the module's behavior changes, update this file in the same PR.

## Details

`ThemeEditor`: a `Card` (440 px wide unless the node says otherwise) that edits the `Theme` in use while the widgets follow. A mode label ("Editing the light theme") over a scroll area (it grows to 520 px, then scrolls) holding **one column** of rows (`rows_column`: the contents of a scroll area lay their children out in a row, which once put every row beside the first two); a "Colors" section with a row per color slot that is opaque in both default themes (`editable_color_slots`, reflected from `ThemeColors`): a `ThemeColorSwatch(slot)` and a `ColorPaletteCombo` marked `ThemeColorSlot(slot)` over `tailwind::COLORS` (the items entity is a child of the editor, `ThemeEditorRefs::colors()`); a pick sets that slot of the half in use through `Theme::set_colors`; and one section per group of `theme_parameters()` with a `NumericStepper` marked `ThemeParameterEditor(name)` per number: radii, border, scroll bar and compact button sizes ("Shapes"), the `font_size_*` type scale ("Text sizes"), the four sides of `item_padding`, `compact_button_padding` and `color_button_padding` ("Padding") and the shadow offsets, spread and blur ("Shadow", through crate-private `Theme::shadow_style_mut`). A `ThemeParameter { name, label, section, min, max }` reads and writes one number (`value` / `apply`, clamped, a `Val` in `Val::Px`, a non-pixel `Val` reads as 0); `every_number_of_the_theme_has_a_row_in_the_theme_editor` walks `Theme` by reflection and fails for a new `Val`, `f32`, `UiRect` or `ShadowStyle` field without a row, so the editor keeps up with the theme. A step (`ValueChange`) sets the number, `show_theme` (when the `Theme` changed or a row was just built) brings swatches, steppers and the mode label back in step, also for changes made elsewhere. Not editable: the fonts (handles to assets) and the translucent shadow colors; there is no export (the `overview` page has it). The rows, labels and swatches are `Pickable { should_block_lower: false }` so the wheel reaches the scroll area over them (`update_scroll_position` only scrolls what is in the hover map; `theme_editor_steps_a_number.ron`). Tests: `WidgetsSetup::ThemeEditor` (a "Change theme" button and the editor), `theme_editor_rows_are_stacked.ron`, `theme_editor_picks_a_color.ron`, `theme_editor_steps_a_number.ron`, and the `theme_editor` headless tests  A row never goes missing because of its value: a number outside its row's range gets a row whose stepper range is widened to include it (`ThemeParameter::range_in`; a step clamps to the same widened range), a number that is not finite (NaN, infinity) shows the row's minimum with a `warn!` naming the parameter and the theme keeps it until a step sets it, and a `Val` that is not in pixels reads as 0 and gets a `warn!` naming the parameter the first time `show_theme` reads it (once per parameter and kind, kept in a `Local`); the first step turns it into pixels (`a_theme_number_above_its_range_still_has_a_row_with_the_range_widened_to_it`, `a_theme_number_that_is_nan_still_has_a_row_at_its_minimum_and_a_warning_names_it`, `a_theme_number_that_is_not_in_pixels_shows_0_and_is_warned_about_once`)
