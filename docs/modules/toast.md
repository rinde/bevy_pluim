# `toast.rs`

`Toast`: a short-lived message stacked along the bottom of its parent.

Read this before changing `src/toast.rs`. When the module's behaviour changes, update this file in the same PR.

## Details

`Toast::new(text)` (`with_duration`, 3 s default; negative and NaN mean 0, so it goes after its first tick, and anything above one day, infinity included, is capped to one day: `ToastTimer::for_duration` is the one place that turns the duration into a timer): a `Card` with the text, spawned as a child of the UI root (`ChildOf(root)`), which moves into the `ToastStack` that is a child of its own parent (an absolute, pointer-ignoring column along the bottom, centred, `GlobalZIndex(1100)`, created by the first toast under a parent, so two roots each get their own) where several stack upwards, newest at the bottom; a toast with no parent has no stack to join: it logs an `error!` and is despawned; a new toast with the text of one showing in the same stack, or of one kept earlier in the same run, is despawned and restarts that one's timer with its own duration (the last of several same-frame duplicates wins), and re-inserting a `Toast` (immutable, like the other display widgets) on a live entity updates text and accessibility label and restarts its own timer with the new duration, keeping its entity and its stack position; empty text keeps the card and normal lifetime. `ToastPlacement { bottom }` (resource, 24 px) is the stack's distance from the bottom edge, for an app to lift above its dock. `place_toasts` runs only while a toast has not moved into a stack (`any_fresh_toast`, a `Without<ToastShown>` query, so an idle frame builds nothing), looking parents up in a `HashMap` of the stacks, and `place_stack` runs only when `ToastPlacement` changed or a `ToastStack` was added (`placement_needs_applying`, so a stack made late still gets an unchanged placement); a stack that has emptied stays, one small node per parent that the next toast there reuses (`toasts-idle` and `toasts-bursting` bench workloads, #678; `a_stack_made_after_idle_frames_gets_a_placement_set_before_it_and_left_unchanged`, `bursts_of_toasts_under_many_parents_keep_one_stack_each_across_idle_frames`, `reinserting_a_shown_toast_after_idle_frames_updates_it_in_its_stack`). A system ticks a private timer with `Time` and despawns the toast when it runs out. `Pickable::IGNORE`, no tab stop; a `Role::Status` node (polite live region) labelled with the text
