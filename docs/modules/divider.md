# `divider.rs`

`Divider`: a 1 px horizontal or vertical rule.

Read this before changing `src/divider.rs`. When the module's behaviour changes, update this file in the same PR.

## Details

`Divider::horizontal()` / `Divider::vertical()`: a 1 px rule in `ThemeColors::divider`, stretching along the other axis unless the caller sets a length
